# Changelog

## 1.0.0

Initial release of the combined SE Ranking + Planable **Marketing Skills** plugin.

21 skills:

- **SEO & AI visibility (9)**: seo-competitor-gap-analysis, seo-competitor-pages, seo-content-brief, seo-ai-search-share-of-voice, seo-ads, seo-local, seo-sxo, seo-agency-landing-page, seo-plan
- **Social media (6)**: draft-post-batch, pending-approvals-roundup, content-calendar-audit, cross-client-metrics-overview, monthly-performance-summary, content-pattern-intelligence
- **Ecosystem (6)**: seo-gaps-to-social-campaign, ai-search-gaps-to-social-campaign, site-audit-to-social-distribution, local-gmb-visibility, client-onboarding-proposal, seo-ai-social-report

Auto-registers both remote MCP servers (SE Ranking + Planable) on install. Skills sourced from [seranking/seo-skills](https://github.com/seranking/seo-skills) v2.10.4 and [Planable/smm-skills](https://github.com/Planable/smm-skills) v1.1.0.
